# Linux Environment Configuration & Automation

This repository contains Linux shell configuration files and Bash automation utilities developed as part of hands-on Linux administration coursework and independent practice.

The project focuses on improving productivity, streamlining administrative tasks, and customizing the command-line environment through Bash configuration, shell aliases, prompt customization, and scripting.

---

## Repository Contents

### Configuration Files

#### .bashrc

Customized Bash startup configuration containing:

- Shell environment settings
- Oh My Posh integration
- Command history preferences
- Administrative helper functions
- Custom shell behavior

#### .bash_aliases

Custom command shortcuts used to simplify common Linux administration tasks and improve terminal productivity.

Examples include:

- Directory navigation shortcuts
- File management aliases
- System maintenance commands

#### ohmyposh.json

Custom Oh My Posh theme configuration used to enhance the command-line interface with:

- Git repository status indicators
- Visual prompt customization
- Context-aware terminal information
- Improved command-line usability
